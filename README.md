第三方测评可以参考两份。vps.dance 在 2023 年 12 月对沪美 IPLC 100GB 档做过完整测试：上海电信入口的 TCP ping 三网平均在 28~33ms（电信 28ms、联通 30ms、移动 33ms），也就是说从国内拨号到专线入口这一段质量不错；机器为 KVM 虚拟化，磁盘 IO 约 294MB/s，Geekbench 5 单核 670 分，出口 IP 归属美国（Nearoute Limited AS51847）。同一份测试里，出口 IP 在 Scamalytics 拿到 0/100 的低风险评分，原生 IP、ChatGPT 可用、TikTok 区域判定为 US，对做店铺和社媒运营来说是加分项；不过 IPQualityScore 给的滥用分偏高，不同数据库结论不一致，对 IP 纯度要求极高的业务最好先小规模验证。

## 买之前必须知道的几条规则

Mkcloud 的购买门槛比一般 VPS 商家高，这几条任何一条不满足都别下单：

1. **实名认证**：所有产品需中国身份信息实名，个人用户要提供手机号、姓名和身份证号且三者一致；企业用户需提交企业名称、营业执照编号、法人身份证号及对公银行账户。
2. **省级白名单**：专线产品只允许一个省份的 IP 连入，下单时在附加选项里选省份，开通后可以修改，但换省份不是随时无感切换的，规划业务时要留出余量。

## 常见问题

**Mkcloud 美国 VPS 的延迟是多少？**
官方标注端内参考延迟 124~134ms（上海入口到美国出口）。实际到美国网站的 ping 会在这个基础上增加出口到目标的延迟，通常在 150~200ms 区间。

**流量是单向还是双向计费？**
两条流量计费线路都按上行+下行双向统计，第三方测评确认套餐页面标注的"1TB"指双向合计。

**可以装 Windows 吗？**
不可以。官方系统列表只有 Linux 发行版，需要 Windows 远程桌面的业务要另找方案。

**和普通美国 VPS 比，为什么贵这么多？**
贵在链路上：国内入口到美国出口走专线内网，不经过拥塞的公网国际出口，同时每个套餐给入口和出口两个独立 IPv4。这些都是实打实的成本项，不是品牌溢价。

**支持哪些付款方式和开通时效？**
支持支付宝，下单后约 1 分钟自动开通，月付起订，支持季付和年付。
